🍹 Fruit/Juice Shop Price Analysis

This script analyzes how different pricing strategies affect a juice shop's revenue.

What it does:

Builds a dataset of prices and corresponding bottles sold
Calculates revenue (Price × Bottles Sold) for each price point
Identifies the price that generates the maximum revenue
Plots a bar chart (price_vs_revenue.png) highlighting the optimal price
Prints a data-driven conclusion recommending the best price point

Run it locally:

bash
pip install pandas matplotlib
python Fruit_analtsis.py
